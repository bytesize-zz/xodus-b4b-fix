# Scoped Back 4 Blood EAC chain watcher

This version is maintained in `bytesize-zz/xodus-b4b-fix`, forked from
`hortelaa/xodus-b4b-fix`. The hardening changes, tests, and revised documentation
were **AI-generated by Hermes Agent (model: gpt-6-astra)** at the fork owner's
request. See [CHANGES.md](CHANGES.md) for the rationale, validation results,
limitations, and AI attribution; original upstream work retains its authorship.

An experimental Linux helper for a specific Back 4 Blood/Xodus chain layout.
It replaces one recognized GDK bootstrapper **only in identified, temporary
Back 4 Blood chains**. A successful file replacement is **not** evidence that
anti-cheat validation or online play works. No compatibility or account/ban-safety
guarantee is provided. Do not run the watcher as root.

## Safety boundary

The watcher considers only immediate children named `.xodus-chain-*` of the
explicitly selected game's parent. It does not recursively watch every game.
Each candidate must contain a regular `Gobi/Binaries/WinGDK/Back4Blood.exe` marker
and `EasyAntiCheat/Settings.json` with **all three** exact values:

```text
productid:    3bc138d96fb24d9597d4bbff23b9ecee
sandboxid:    57dfd95548214a138218e56cd9e5b9d8
deploymentid: e052f3c4fce741bab494ed0304eeaf62
```

Only `EasyAntiCheat/EasyAntiCheat_EOS_Setup.exe` is eligible. Unknown versions
are skipped with a diagnostic. The recognized GDK input SHA-256 is:

```text
2cf5f353a0bf669e7e66c93cd8e346c7b32dbc55f1c6961ce91caadfe0d9ed67
```

That input hash was measured from the local GDK installation; it is a version
allowlist, not an authenticity assertion. The original game's EAC executable is
never a replacement target. Hardlinked chain files are replaced by atomic rename
of a new file, not overwritten in place. Symlinks in directory components,
markers, and write destinations are rejected; filesystem operations use directory
file descriptors and `O_NOFOLLOW`. FIFOs/devices are not treated as regular files.

**Read-only chain-settings exception:** Xodus launch views symlink nondecrypted
files back to the installation. A chain's `EasyAntiCheat/Settings.json` may therefore
be a regular file, or a symlink naming **exactly the selected original game's**
`EasyAntiCheat/Settings.json`. Only the exact absolute target or its canonical
relative spelling from the chain's `EasyAntiCheat` directory is accepted. Leading
`..` components needed by that relative spelling are allowed; other traversal
spellings/detours, broken links, and foreign-game settings links are rejected,
even when the foreign file contains identical IDs. The watcher never follows this
link: it securely opens the selected original's directories and regular settings
file with `O_NOFOLLOW`, checks the link text and metadata before/after the read,
and repeats identity validation before replacement. Settings are never written.
The original installation's validation (including installer validation) remains
strict: its settings must be a regular file, not a symlink. The chain's
`Back4Blood.exe` marker and EAC replacement target must still be regular files.

## Bundled-file trust

The bundled executable's Authenticode signature was independently verified with
`osslsigncode` 2.13: EasyAntiCheat Oy signer, GlobalSign chain, DigiCert timestamp
**February 20, 2024, 11:41:02 UTC**, signature and timestamp CRL verification
successful. This statement concerns exactly the executable hash below, not future
updates. The verification report is retained at `audit/authenticode-verification.txt`.
It includes the tool's warning about an expired signer certificate during CRL
validation; timestamp and final signature checks succeeded. The installer does
not perform a fresh network/certificate-revocation check.

**The authenticity of `runtime.conf` has not been independently established.**
Neither the signature nor matching IDs prove this transplant is compatible,
approved by the game publisher, or safe for an account.

`watcher.py` pins both bundled files:

```text
94567bf0dfcf48bfd6a2fa073e854ff6c8fb38ea114d5913dbe2c1d2554bcaae  EasyAntiCheat_EOS_Setup.exe
06f8fc9302d4636d30db3866fdccafac79bd646a51e703200caf8a325bcbf5e9  runtime.conf
```

These hash checks detect changed bundle bytes relative to this code. Hashes alone
are **not proof of authenticity**, and do not protect against an attacker changing
both the code and its pins. Missing or mismatched bundle files cause startup to
fail before `READY` and before installer writes.

## Requirements and installation

Linux, Python 3.8 or later, working inotify and `/proc/self/fd`, and a writable
filesystem supporting atomic rename and directory fsync. No third-party Python
packages or `inotify-tools` are required. The installer never installs packages,
uses `sudo`, starts the watcher, launches the game, or executes the bundled EXE.

Stop any old broad `inotifywait` watcher before using this version. Updating its
script on disk does not stop an already-running old process.

Run explicitly (replace the example path with your installation):

```sh
sh install.sh \
  --game-dir '/path with spaces/Xodus Nexus/Back-4-Blood' \
  --accept-bundled-files
```

`--accept-bundled-files` acknowledges the unverified `runtime.conf` authenticity
and compatibility/account risks; there is no silent acceptance. The supplied game
must itself pass the three-ID and marker checks. Paths containing `..`, control
characters, or symlink components are rejected rather than normalized through them.
Ordinary spaces, apostrophes, double quotes, dollar signs, backticks, percent signs,
and backslashes are safely quoted in generated launchers.

The installer writes:

- `<game-parent>/b4b-eac-fix/watcher.py` and `files/`: independent installed copies.
- `<game-parent>/b4b-eac-fix.sh`: shell launcher with quoted arguments.
- `~/.local/share/applications/b4b-eac-fix.desktop`: terminal launcher with Desktop
  Entry/Exec escaping. `--applications-dir PATH` overrides the menu directory.
- `<game>/EasyAntiCheat/Certificates/runtime.conf`: **only if absent**, creating the
  certificates directory if necessary. An existing regular configuration is
  preserved byte-for-byte. Symlink/nonregular configurations are rejected.

Replaced installation files receive adjacent `.backup-<unique-id>` copies before
replacement. Reinstalling preserves `runtime.conf`. Each file replacement is
atomic, but the entire installation is **not** a transaction: disk-full/permission
errors can leave a partial install; errors are reported and backups remain. Do not
run simultaneous installers. The installer does not alter the original EAC EXE.

## Run

Open **B4B EAC Watcher** from your application menu, or:

```sh
sh '/path with spaces/Xodus Nexus/b4b-eac-fix.sh'
```

Wait for `READY: scoped inotify watches active`, then launch the game through Xodus.
`REPLACED` means only the chain file was atomically replaced. Regular companion
`.lock` files and transient missing files during assembly are silent. A chain
that remains incomplete for 10 seconds emits one `WAIT` notice while retries
continue. `SKIP` still reports validation/safety failures; `ERROR` is fatal.
Stop with Ctrl+C when finished.

For development, the helper can also run directly, without installing anything:

```sh
python3 watcher.py --game-dir '/path with spaces/Xodus Nexus/Back-4-Blood'
```

This direct command still changes eligible chain files while it runs, but does not
install a runtime configuration. `--source-dir PATH` selects a bundle directory;
the same fixed pins apply, so it does not permit arbitrary replacement binaries.

## Timing and security limitations

- The helper uses Linux inotify `close_write`/`moved_to` notifications. Observed
  creates/modifications block replacement until a close-write or moved-to event.
  Directory creation/moves trigger scoped rescans; a 100 ms reconciliation loop
  also covers events during new-watch registration.
- Existing files and files found in newly assembled/moved directories must have
  unchanged inode/size/mtime/ctime for at least 300 ms before consideration. A
  file opened **before its directory watch was attached** may still have an open
  writer despite that quiet interval. This is not a race-free handoff protocol.
  The full known-input hash check and final metadata recheck reduce, but cannot
  eliminate, concurrent-creation races. There is no guarantee of replacement
  before Xodus/the game opens the file. A synchronous Xodus assembly hook would
  be needed for that guarantee. The settle delay intentionally prioritizes
  safety over winning the launch race.
- The watcher is not a security boundary against a hostile process running as the
  same user (or root). Descriptor-relative operations avoid symlink traversal;
  they cannot make the multi-file identity checks and directory renames one atomic
  transaction. Do not use attacker-controlled game parents or bind-mount tricks.
- All matching Back 4 Blood chains under the chosen parent are eligible, not only
  the most recently created one. Other layouts, IDs, or bootstrapper revisions
  fail closed. Already-matching bundle bytes need no replacement.
- Queue overflow, inability to add a watch, or a changed games-parent directory
  stops the watcher; do not ignore that failure and launch anyway.
- No live-game online session has been verified by this test suite. The old
  `PR_PLAN.md` is historical proposal material, not evidence of runtime success.

## Tests (no game or bundled executable is launched)

```sh
python3 -m unittest discover -s tests -v
```

Tests create temporary fake installations, start real Linux inotify watcher
subprocesses, and exercise close-write, moved-to, newly created/moved directories,
existing chains, repeated replacement, wrong IDs, missing markers, unknown bytes,
unrelated/nested directories, accepted absolute/relative selected-game settings
links (with original bytes/inodes unchanged), foreign/broken/traversal settings
links, settings-link changes during validation, nofollow reads of the original,
other rejected symlinks, FIFOs, hardlinks, missing/tampered bundles,
explicit acknowledgment, reinstall backups/configuration preservation, and hostile
path quoting. They also start the generated shell launcher and, when available,
run `desktop-file-validate` on its Desktop Entry. Only the accepted GDK input hash
is substituted in the isolated test helper to recognize synthetic old-file bytes;
the shipped bundle hashes remain real and are checked. Temporary fixtures do not
require or modify an actual game installation.

## Removal

Stop the watcher. Remove its installed `b4b-eac-fix/` directory, `b4b-eac-fix.sh`,
and menu entry after inspecting any adjacent backups you want to retain. Do not
blindly delete `runtime.conf`: it may have predated this installer. Restore old
installation files from their backups only if you intend to use them; the old
broad watcher remains unsafe.
